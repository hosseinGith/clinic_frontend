# MedFlow — سیستم رشد و عملیات کلینیک زیبایی (Aesthetic Clinic Operations Platform)

نسخه‌ی بازمهندسی‌شده‌ی پلتفرم مدفلو (MedFlow) بر پایه‌ی معماری شش‌ضلعی (Hexagonal Architecture / Ports & Adapters) با React 18، TypeScript، Tailwind CSS v3، React Router v6، TanStack Query و Vitest.
سامانه کاملاً فارسی، راست‌چین (RTL)، متناسب با تقویم شمسی جلالی و ارقام فارسی طراحی شده است و لایه‌ی اتصال به بک‌اند به‌گونه‌ای پیاده‌سازی شده که با تغییر یک متغیر محیطی، بدون دست‌زدن به کامپوننت‌های UI، امکان اتصال به API واقعی فراهم است.

---

## ۱. ویژگی‌های کلیدی (Key Features)

- **رابط کاربری تمیز و مینیمال پزشکی:** رنگ اصلی Teal (`#0f766e`)، پس‌زمینه `#fafafa`، کارت‌های سفید با بوردر لطیف، و تایپوگرافی چشم‌نواز Vazirmatn.
- **داشبورد عملیاتی هوشمند:**
  - ۴ کارت شاخص‌های کلیدی متصل به مخزن داده (۲۴ نوبت امروز، ۷ سرنخ داغ با ۳ آماده تصمیم‌گیری، ۳ مشتری در خطر با ۱۲٫۸ میلیون تومان ارزش بازیابی، ۹۲٪ نرخ پاسخگویی).
  - صف ۵ نوبت بعدی با تغییر وضعیت پویا مبتنی بر ماشین حالت نوبت (`appointmentStatus.ts`).
  - پنل وضعیت اتوماسیون‌های هوشمند با نشانگر سلامت (`healthy`).
  - کارت‌های اقدامات پیشنهادی بعدی مبتنی بر ارزش مالی و احتمال تبدیل.
  - ثبت دستی نوبت توسط پذیرش در مودال اختصاصی.
- **ویزارد ۴ مرحله‌ای رزرو آنلاین (`/book/:clinicSlug`):**
  - محاسبه واقعی اسلات‌های خالی براساس ساعات کاری، مدت خدمت، روزهای هفته و تعارض نوبت‌های ثبت‌شده.
  - اعتبارسنجی فرم با کتابخانه Zod و نرمال‌سازی شماره موبایل ایرانی (`09xxxxxxxxx`).
  - ثبت نوبت در صف پذیرش کلینیک با وضعیت `pending_confirmation` و بازخوانی آنی داشبورد (Query Invalidation).
- **معماری ماژولار و تفکیک لایه‌ها:**
  - `src/domain/`: مدل‌های خالص کسب‌وکار و ماشین حالت.
  - `src/services/repositories/`: اینترفیس‌های مخازن داده.
  - `src/services/adapters/mock/`: پیاده‌سازی با LocalStorage و داده‌های آغازین (Seed).
  - `src/services/adapters/http/`: اسکلت کامل ارتباط با بک‌اند REST API و مپرهای DTO.
  - `src/integrations/`: پورت‌ها و آداپتورهای سرویس‌های بیرونی (پیامک، واتساپ، پرداخت) به همراه رجیستری زنده وضعیت.

## ۲. دستورات اجرا و تست (Run Commands)

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای محیط توسعه (Dev Server)
```bash
npm run dev
```

## ۳. تنظیم متغیرهای محیطی (`.env`)

فایل نمونه `.env.example` در ریشه‌ی پروژه قرار دارد. برای سوییچ به حالت بک‌اند واقعی:

```env
# انتخاب آداپتور مخزن داده: mock یا http
VITE_DATA_SOURCE=mock

# آدرس پایه سرویس‌های REST API
VITE_API_BASE_URL=https://api.medflow.ir/v1

# تنظیم ارائه‌دهنده پیامک (mock یا kavenegar)
VITE_SMS_PROVIDER=mock
VITE_SMS_API_KEY=

# تنظیم ارائه‌دهنده پرداخت (mock یا zarinpal)
VITE_PAYMENT_PROVIDER=mock
VITE_PAYMENT_MERCHANT_ID=
```

## ۴. مسیرهای سامانه (Application Routes)

- `/` → **داشبورد عملیاتی کلینیک** (صف نوبت‌ها، شاخص‌ها، اتوماسیون‌ها، اقدامات)
- `/appointments` → **لیست جامع نوبت‌ها**
- `/clients` → **مشتریان و مراجعان** (همراه با وضعیت مشتری در خطر بازگشت)
- `/leads` → **سرنخ‌های فروش و مشاوره** (برچسب‌های داغ و آماده تصمیم‌گیری)
- `/messages` → **صندوق پیام‌ها و تاریخچه پیامک/واتساپ ارسالی اتوماسیون**
- `/settings` → **تنظیمات و وضعیت اتصال سرویس‌های پیامک، واتساپ و درگاه پرداخت**
- `/marketing` و `/reports` → **صفحات بازاریابی و گزارش‌ها**
- `/book/:clinicSlug` → **پرتال عمومی رزرو آنلاین نوبت** (مثال: `/book/ariana`)
- `*` → **صفحه ۴۰۴**
